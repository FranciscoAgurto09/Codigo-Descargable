# Manual educativo de sistemas embebidos y plataformas de desarrollo

Repositorio de códigos descargables que acompañan al manual impreso.
Cada unidad del libro tiene su carpeta, y dentro de ella los sketches de las
prácticas guiadas y de los ejercicios propuestos.

## Unidades

| Unidad | Plataforma | Carpeta |
|---|---|---|
| 1 | Arduino Uno R3 | [`unidad-01-arduino-uno-r3/`](unidad-01-arduino-uno-r3/) |

## Nomenclatura

- `U1-P01` → **P**ráctica guiada 01 de la **U**nidad **1**
- `U1-E01` → **E**jercicio propuesto 01 de la **U**nidad **1**

El código impreso en el encabezado de cada práctica o ejercicio del libro
coincide exactamente con el nombre de la carpeta y del archivo `.ino`.

## Requisitos

- Arduino IDE 2.x (o 1.8.x)
- Placa Arduino Uno R3 o compatible
- Cable USB **de datos** (los cables de solo carga no funcionan)
